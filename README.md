# Counterfeit Banknote Detection with Machine Learning

This project was completed as part of the OpenClassrooms Data Analyst training program.

The objective was to build and evaluate machine-learning models capable of identifying counterfeit banknotes from six geometric measurements, then provide a reusable prediction script.

---

## Project Context

The dataset contains 1,500 banknotes described by six geometric features and a binary target indicating whether each note is genuine.

The project covers data quality analysis, missing-value imputation, supervised classification, unsupervised clustering, model comparison, and model reuse.

---

## Objectives

- Explore the geometric characteristics of genuine and counterfeit banknotes
- Treat missing values in the `margin_low` feature
- Train and compare several classification models
- Evaluate model performance with business-relevant metrics
- Investigate natural groupings with K-Means
- Save the selected model and provide a prediction script

---

## Modeling Approach

1. Exploratory data analysis and data-quality checks
2. Linear-regression imputation of 37 missing `margin_low` values
3. Stratified 80/20 train-test split
4. Logistic Regression, K-Nearest Neighbors, and Random Forest classification
5. K-Means clustering with two groups
6. Model evaluation with confusion matrices, precision, recall, F1-score, ROC curves, and AUC
7. Selection and serialization of the final model

---

## Key Results

- All three supervised models reached 99% accuracy on the 300-note test set
- The models correctly identified 98 of 100 counterfeit notes
- Counterfeit-note sensitivity: 98%
- Specificity: 99.5%
- Random Forest achieved the highest AUC at approximately 0.99935 and was selected as the final model
- K-Means revealed two meaningful groups with a silhouette score of approximately 0.51
- The linear imputation model achieved an MAE of 0.335 mm and an R² of 0.546
